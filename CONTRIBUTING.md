# Contributing to Persian Font for OpenProject

Thank you for your interest in contributing to **Persian Font for OpenProject**!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Sepehr-Safaeian/openproject-persian-font.git
   cd openproject-persian-font
   ```

2. Install development dependencies:
   ```bash
   bundle install
   ```

3. Run the test suite:
   ```bash
   bundle exec rspec
   ```

4. Check code style with RuboCop:
   ```bash
   bundle exec rubocop
   ```

## Pull Request Guidelines

- Ensure all RSpec tests pass.
- Write unit tests for any new features or bug fixes.
- Maintain idempotent behavior in font installation tasks.
- Keep commits clear, descriptive, and focused.
